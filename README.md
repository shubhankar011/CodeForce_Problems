# Competitive Programming Solutions

A collection of solutions to problems from [CodeChef](https://www.codechef.com/) and [Codeforces](https://codeforces.com/), written in C++.

---

## Structure

```
.
├── CodeChef/       # CodeChef problem solutions
├── CodeForce/      # Codeforces problem solutions
└── LeetCode/       # LeetCode problem solutions
```

---

## Topics Covered

- **Dynamic Programming** — SUPW, IPL, ZeroOneTiles, ClimbingStairs, 455A
- **Sliding Window** — 279B, 363B, Chewing_Gum, Variation
- **Binary Search** — BambooArt, Wormholes, 706B
- **Two Pointers** — Chewing_Gum, 381A
- **Greedy** — Bookshelves, Tournament, smart_phone
- **Sorting** — 337A, bubble_sort
- **Strings** — 112A, 474A, 266B, 59A, reverse, longest_palindrome
- **Stack/Brackets** — MatchedBrackets
- **Recursion** — subset_recursion, fibo, binary_search, isSort
- **Simulation** — Video_game, end_of_corruption, discrepancies_voter_list
