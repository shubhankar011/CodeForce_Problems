# Competitive Programming Solutions

A collection of solutions to competitive programming problems from various platforms.

## Contents

Currently contains solutions to CodeForces problems written in C++.

## Languages

- C++ (100%)

## Planned Additions

This repository is intended to include solutions from:
- CodeForces
- CodeChef
- LeetCode
- ZCO (Zonal Computing Olympiad)
- INOI (Indian National Olympiad in Informatics)
- IARCS

## Usage

Each file is a standalone solution. Compile with a C++ compiler:

```bash
g++ -o solution <filename>.cpp
./solution
```

## Structure

Solutions are currently organized by platform and problem number. As the repository grows, consider organizing into directories by platform.
